# Deviation 04.1 - Results code: Phase 04 keeps its own results module

Status: accepted 2026-10-04 by the agent under delegation; the author may overturn it
Phase: `spec.md` and `plan.md` in this folder

## What happened
Spec scope item 5 asks for the results table "reusing the Phase 03 results code rather than adding per-phase stage code", and plan D7 asks for the class-check, cost and page code to be parameterized inside `fusion_results.py` by a phase description.
Increment 7 instead added `src/edge_rag/judge_results.py`, which holds Phase 04's own set table, cost rows, class check and page.
What it shares with `fusion_results.py`: the states, the advance rule and the verdict (the frozen selection rule), the inherited cost labels (`handover_cost`) and the byte-equal write and regeneration of `results.json` and `results.md` (`write_pair`, `regenerate`).
The reason given in increment 7: the rows, bounds and components differ (judged units, the 1 s GPU bound, the hop rows).
Phase 03's page still regenerates byte-equal (sha256 e50c85a9ca1e201dd30cbc50bde426c5fddeab638e2c4f53e3c04d3227e0a9a9, measured).
The plan first recorded the split as "a plan-level split, no criterion changes"; that was wrong, because scope item 5 is part of the frozen spec.
Phase 04's results (increment 10) were measured with `judge_results.py`.

## Options
| Option | Effect on criteria | Cost | Risk |
|---|---|---|---|
| A. Keep the split for Phase 04; the next phase's spec decides whether the results code is merged into one shared module before a third phase adds its own | spec scope item 5 deviated, recorded; no criterion, rule, bar or figure changes | none now | a third copy of the set table and page if the next spec does not decide |
| B. Refactor now into one module parameterized by phase | meets scope item 5 as written | a refactor of measured code | re-opens measured outputs: both results pages must be re-proven byte-equal after the fact |

## Proposal
Option A: the results were measured with the split, and a refactor now would re-open measured outputs for no change in any figure.

## Decision
Agent under delegation, 2026-10-04: option A.
Spec scope item 5 is deviated and recorded here; no criterion changes.
The next phase's spec must decide whether to merge the results code into one shared module before adding a third.
The author may overturn this decision.
Author, 2026-10-04: overturned; Phase 05 merges the results code with Phase 03's (master plan, decision log).
