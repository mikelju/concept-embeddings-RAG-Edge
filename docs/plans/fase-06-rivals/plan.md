## Decisions taken during execution
- D7. G-R2 runs in float32, scorer and card reference alike (decided 2026-10-06 before any pod run, revising the first draft's bfloat16).
  Reason: the reference scores one pair per call without padding and the determinism check changes batch composition and padding; in bfloat16 those alone can move P(yes) past the frozen 1e-3, which would abort G-R2 for numeric noise rather than infidelity; in float32 they stay near 1e-6.
  The card's reference code runs verbatim except an explicit float32 `dtype` at load (its own load would resolve the checkpoint's bfloat16 under the pinned `transformers==5.16.1`); the reference dtype is recorded in the check JSON.
  Cost: about 1.8e8 tokens over the three sets (about 150 tokens per pair, derived from pair-file sizes) at about 30 TFLOP/s effective float32 on a 4090 is about 2 h of scoring, about 1.5 USD (projection), inside G-R2's 3.3 USD hard cut; the plan's earlier 3.0 h estimate stands as the conservative figure.
  Batch 16 and maximum length 8,192 are Phase 02's fixed `QwenReranker` settings, unchanged.
- D8. C3 compares the model card's score, P(yes), within 1e-3 absolute: fidelity against the card's reference code run one pair per call (no padding), determinism against the same 300 pairs scored in reversed order (other batch composition and padding). The stored score is log P(yes) (Phase 02 code, free of saturation ties); its reversed-order difference is recorded, not gated, because a log near 0 probability magnifies bfloat16 noise without changing the order of the pairs that matter. Reason: the spec names no space and the card's output is P(yes).
- D9. The subsample file keeps the order `sample` returns, one qid per line, so its bytes are the rule's output; consumers read it as a set.

- E1. The training rule's "QASPER data" means QASPER questions, answers or annotations; S2ORC paper text that may contain QASPER's source papers (GritLM's E5S) is labelled "corpus text possibly seen" and does not make a rival an upper reference; undisclosed LLM pretraining is treated the same way.
  Decided by the agent under the author's delegation, 2026-10-06; it matters for Phase 07, since G-A2 does not touch QASPER here.
